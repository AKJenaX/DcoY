# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub Issues.**

If you discover a security vulnerability in DcoY, we ask that you report it privately to our team. This allows us to coordinate a fix and release a patched version before public disclosure.

To report a vulnerability, please email **security@dcoy.org** with the following details:
1. Description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or code snippets.
3. System details (OS, Python version, configurations).

We will review your submission and reply within 48 hours to confirm receipt and discuss a remediation plan.

---

## Supported Versions

Only the latest release (current version `v0.1.0-alpha`) is actively supported with security updates. We recommend always running the latest code to ensure maximum defense capabilities.
